# Portfolio

시스템 소프트웨어 개발자 최성운의 포트폴리오 웹사이트입니다.

## 구조

```
portfolio/
├── backend/   # Spring Boot REST API
└── frontend/  # React + Vite
```

## 기술 스택

**Backend**
- Java 21, Spring Boot 3.5
- Spring Security + JWT 인증
- Spring Data JPA + PostgreSQL
- Gradle (Kotlin DSL)

**Frontend**
- React 19 + TypeScript
- Vite, Tailwind CSS 4
- Framer Motion
- React Router
